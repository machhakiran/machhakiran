### 🌐 Executive Profile

I am **Kiran Machha**, a **Forward Deployed AI Engineer** based in **Singapore**, specializing in **Sovereign AI Infrastructure**, **Autonomous Multi-Agent Systems**, and **Air-Gapped Enterprise AI Platforms**.

I bridge the gap between frontier AI research and resilient enterprise operations:
- 🏛️ **Sovereign AI & Air-Gapped Deployments**: Packaging multi-model inference stacks (`vLLM`, `llama-server`, `Ollama`) with zero cloud data egress and automated hardware auto-tuning across **NVIDIA CUDA**, **Apple Silicon Metal**, and **AMD ROCm**.
- 🤖 **Autonomous Agents & Tool Orchestration**: Architecting production agent loops around the **Model Context Protocol (MCP)**, **OpenClaw**, and **Hermes Agent** harnesses with stateful SQLite memory and self-correcting reflection loops.
- 🧠 **Enterprise Hybrid RAG & Vector Systems**: Designing dual-engine retrieval architectures with **OpenSearch 2.19** (BM25 keyword matching + dense vector embeddings with Reciprocal Rank Fusion) and **sub-2ms Redis semantic caching**.
- 🛡️ **Enterprise Grounding**: Backed by a strong engineering foundation in regulated banking change control, microservices, and Kubernetes GPU node pool management.
